# voicerec

Наговорить текст (например, ТЗ для ИИ) в микрофон и получить его в файле.
Локально и офлайн: [whisper.cpp](https://github.com/ggml-org/whisper.cpp) + модель `large-v3-turbo-q5_0`.
Звук никуда не уходит.

## Установка

```bash
git clone <repo> ~/voicerec
cd ~/voicerec
./setup.sh
source ~/.bashrc
```

`setup.sh` делает всё сам:

1. Ставит пакеты через `apt` (спросит пароль sudo). Под видеокарту — автоматически:
   NVIDIA → `nvidia-cuda-toolkit`, AMD/Intel → Vulkan, иначе только CPU.
2. Подтягивает сабмодуль whisper.cpp (`src/`, версия закреплена в репозитории) и собирает его под найденный бэкенд.
3. Скачивает модель `large-v3-turbo-q5_0` (~550 МБ) и VAD `silero-v6.2.0` (~1 МБ) в `models/`. Оборванная загрузка докачивается.
4. Добавляет `bin/` в `PATH` через `~/.bashrc`.

Без sudo или с уже стоящими пакетами: `./setup.sh --no-packages`.
Сменили видеокарту или драйверы — запустите `./setup.sh` ещё раз.

Не Debian/Ubuntu — поставьте аналоги пакетов из `setup.sh` (`install_packages`)
и запустите `./setup.sh --no-packages`.

### NVIDIA

Нужен проприетарный драйвер (`nvidia-smi` должен работать) и репозиторий `non-free`
(Debian) для `nvidia-cuda-toolkit`. Проверка, что сборка взяла GPU: в выводе `vr-build`
строка `backend: CUDA`.

## Использование

| Команда | Что делает |
|---|---|
| `vr [файл]` | запись до Enter/Ctrl+C → текст дописывается в конец файла и печатается в stdout |
| `vr toggle [файл]` | для горячей клавиши: первый вызов — старт, второй — стоп и расшифровка (уведомление) |
| `vr meet [файл]` | запись встречи: микрофон + звук компьютера, реплики с временем и меткой «Я»/«Собеседники» |
| `vr meet toggle [файл]` | то же для горячей клавиши |
| `vr-transcribe <файл>` | расшифровать любой аудиофайл |
| `vr-transcribe --meet <файл>` | расшифровать запись встречи по каналам |
| `vr-model <name>` | скачать другую модель (`large-v3-turbo`, `small`, `medium`, `large-v3`) |
| `vr-build` | пересобрать whisper.cpp (после смены железа/драйверов) |

Каждая запись сохраняется в `recordings/<дата>.ogg` (Opus 24 кбит/с, ~180 КБ в минуту) и `.txt`;
перерасшифровать: `vr-transcribe recordings/<дата>.ogg`.

Файл необязателен: без него текст остаётся только в `recordings/`. С файлом каждая запись
дописывается в конец отдельным абзацем, так ТЗ удобно наговаривать по кускам:

```bash
vr tz.md   # контекст задачи, Enter
vr tz.md   # требования, Enter
vr tz.md   # что не трогать, Enter
```

Потом `tz.md` правится руками и отдаётся ИИ (например, `claude "$(cat tz.md)"`).

### Встречи (Google Meet, Zoom, ...)

`vr meet` пишет стерео: левый канал — микрофон, правый — всё, что играет в динамиках
(monitor-источник PulseAudio/PipeWire). Каналы расшифровываются отдельно и склеиваются по времени:

```
[00:00:05] Я: Давайте по срокам. Что успеваем к пятнице?
[00:00:11] Собеседники: Бэкенд готов, фронт ещё в работе...
```

Кто именно из собеседников говорит — не различается, все они в одном канале.
Без наушников микрофон слышит собеседников; такие дубли с меткой «Я» убираются
по совпадению времени и текста (`VR_MEET_DEDUP=0` — выключить).
Пошагово, включая выводы через ИИ: [HOWTO-meet.md](HOWTO-meet.md).

### Горячая клавиша

Привязать `~/voicerec/bin/vr toggle ~/tz.md` в настройках клавиатуры рабочего стола
(GNOME: Настройки → Клавиатура → Свои сочетания). Нажали — говорите, нажали ещё раз —
текст дописан в `~/tz.md`. Путь лучше указывать абсолютный.

## Настройка

`config.sh`, любую переменную можно переопределить окружением (`VR_LANG=en vr`):

- `VR_LANG` — язык (`ru`, `en`, `auto`);
- `VR_VAD` — вырезать тишину перед распознаванием (по умолчанию `1`). Без него whisper
  на паузах выдумывает фразы вроде «Продолжение следует...»;
- `VR_PROMPT` — словарь терминов: whisper берёт из него написание (латиница, регистр).
  Впишите свои названия проектов и технологий;
- `VR_DEVICE` — микрофон, список: `arecord -L`;
- `VR_MEET_MIC`, `VR_MEET_SPEAKERS` — источники для `vr meet` (по умолчанию системные
  микрофон и выход), список: `pactl list short sources`; `VR_MEET_ME`, `VR_MEET_THEM` — метки;
  `VR_MEET_DEDUP` — убирать эхо собеседников из канала микрофона (по умолчанию `1`);
- `VR_MODEL_NAME` — модель (`large-v3-turbo-q5_0`, `large-v3-turbo`, `small`...),
  `VR_THREADS` — потоки CPU.

## Если не работает

- **Пустой текст / тишина** — не тот микрофон. `arecord -L`, выбрать устройство в `VR_DEVICE`;
  проверить запись: `arecord -d 3 /tmp/t.wav && aplay /tmp/t.wav`.
- **Медленно** — сборка ушла на CPU: смотрите строку `backend:` в выводе `vr-build`.
  Для проверки скорости возьмите модель поменьше: `vr-model small`,
  `VR_MODEL_NAME=small vr`.

## Обновить whisper.cpp

`src/` — git submodule, версия закреплена коммитом этого репозитория:

```bash
git submodule update --remote src
vr-build
git commit -am "Bump whisper.cpp"
```
