# Как записать встречу и получить выводы

## 1. Перед встречей

- Лучше в наушниках: без них микрофон ещё раз слышит собеседников с небольшой задержкой,
  и речь распознаётся хуже.
- Микрофон пишется напрямую из системы: кнопка «выключить микрофон» в Meet/Zoom его
  не глушит, разговоры рядом с компьютером тоже попадут в запись.
- При запуске `vr meet` спросит микрофон и звук компьютера (Enter — оставить прошлые).
  Звук компьютера — монитор того выхода, через который идёт звонок: если в браузере или Zoom
  выбран не системный выход, выберите его монитор.

## 2. Запись

```bash
vr meet ~/meetings/2026-10-17-planning.md
```

Начните запись за пару секунд до начала встречи: первые 1–2 секунды теряются, пока
просыпаются аудиоустройства. После встречи нажмите Enter. Расшифровка часовой встречи на
видеокарте займёт несколько минут.

С горячей клавишей: привязать `~/voicerec/bin/vr meet toggle ~/meetings/meet.md`.
Первое нажатие начинает запись, второе её заканчивает.

## 3. Результат

В указанном файле (и в `recordings/<дата>-meet.txt`):

```
[00:00:05] Давайте по срокам.
[00:00:07] Что успеваем к пятнице?
[00:00:11] Бэкенд готов, фронт ещё в работе...
```

Звук остаётся в `recordings/<дата>-meet.ogg`. Если расшифровка не понравилась (сменили модель,
дописали термины в `VR_PROMPT`), перерасшифруйте:

```bash
vr-transcribe --meet recordings/<дата>-meet.ogg > meet.md
```

Старые записи, где микрофон и звук компьютера были в разных каналах, перерасшифровываются
так же: каналы сводятся в один.

## 4. Выводы через ИИ

```bash
claude -p "Это расшифровка встречи, говорящие не размечены.
Выдели: принятые решения; задачи (кто, что, срок); открытые вопросы.
$(cat ~/meetings/2026-10-17-planning.md)"
```

Расшифровка — это распознанная речь, в ней бывают ошибки в терминах и именах. Спорные места
проверяйте по записи, время каждой фразы указано в начале строки.
